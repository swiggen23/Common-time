# Common Time

Group scheduling polls with no accounts. Propose dates and times, share one link, and everyone taps Yes, Not ideal or No. The best time rises to the top.

- `public/index.html`: the whole front end (no build step)
- `netlify/functions/api.mts`: the API, stored in Netlify Blobs
- Deploys on Netlify; `netlify.toml` sets the publish and functions folders
